Νταντάδες της γειτονιάς

React + Firebase (Auth, Firestore). Αναζητήσεις, προφίλ, ραντεβού, συμβάσεις, πληρωμές, μηνύματα. Gov-style UI.

Εκκίνηση

npm install
npm start

Build: npm run build → build/

Stack
UIReact 19
RouterReact Router 6
ΔεδομέναFirebase Auth + Firestore
Buildreact-scripts

Config: src/firebase.js · Routes: src/App.js
